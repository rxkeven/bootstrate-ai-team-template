# Bootstrate Default Brand

Fallback brand standards for Bootstrate-powered ops repos not yet customized. Agents and the dashboard script use these when instance brand files still contain placeholder values.

## Voice

Direct. Technical. No padding. Active voice, recommendation first, reasoning second.

## Tone

Confident and specific. Short sentences. No hedging. Name the thing; use numbers where they exist.

## Visual identity defaults

Used by the dashboard when `visual-identity.md` is unpopulated:

| Key | Default value |
|-----|---------------|
| `primary` | `#1e293b` |
| `accent` | `#3b82f6` |
| `background` | `#f1f5f9` |
| `text` | `#0f172a` |
| `surface` | `#ffffff` |
| `border` | `#e2e8f0` |
| `font_family` | `Inter, system-ui, sans-serif` |
| `font_family_mono` | `ui-monospace, monospace` |

## When this is in use

Reading this file is expected immediately after bootstrap. Replace `visual-identity.md` and `guidelines.md` with real brand content before client-facing volume picks up.
