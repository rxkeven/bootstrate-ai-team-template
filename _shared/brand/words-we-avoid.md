## Default avoidance list

These are common written-AI tells or hedging patterns that consistently weaken external-facing copy. Until customized, agents flag any of the following in drafts and propose an alternative:

| Avoid | Why | Try instead |
|---|---|---|
| "delve into" | AI tell | "look at," "explore" |
| "navigate the landscape" | Cliché plus AI tell | Name the actual thing being navigated |
| "in today's fast-paced world" | Filler opener | Cut entirely; start with the substance |
| "robust" | Vague | A specific attribute that says what is robust |
| "leverage" (as a verb) | Corporate hedging | "use" |
| "synergy" / "synergize" | Empty | Name the actual collaboration |
| "I think maybe" / "I might be wrong but" | Hedging | State the recommendation; uncertainty can follow as a separate sentence |
| "Just wanted to" / "Just checking in" | Apologetic openers | Lead with the question or the update |
| "It is worth noting that" | Wind-up | Start with the noteworthy thing |
| Em-dashes in external content | AI tell on external-facing copy | Comma, semicolon, or period per the em-dash rule in voice-guidelines.md |
