# Standup Skill

Async daily digest of every looping role's state. Read-only: reads existing repo data and writes one file. Sends no messages and changes no state.

## What it does

Collects the current state of every looping role and writes a single one-page digest to `war-room/standup-{YYYY-MM-DD}.md`: one short block per role — **wrapped**, **queued**, **blocked**.

## When to run it

Once per business day, early. Run as a step PM takes at the start of its first loop of the day, or on {CEO_ROLE}'s request. Safe to run more than once; each run overwrites that day's file.

## Roles to include

Every looping role:

- Active loop: `pm`, `coordinator`
- Work-driven: `hr-manager`, `engineer`, `portfolio-manager`
- Scheduled Cowork: `pa-cowork`

On-demand roles (`designer`, `strategist`, `validator`, `ccs`, `board`) — include a one-line note only if they have open work this cycle; skip otherwise.

## Sources — per role

Read via `{GITHUB_MCP}__get_file_contents` (owner={COMPANY_SLUG}, repo={COMPANY}-ai-ops). Use what exists; never invent.

1. **Latest handoff** — the lexically-last file in `_handoff/{role}/`. Primary source.
2. **Inbox depth** — count of items in `_inbox/{role}/` (ignore `.gitkeep`). Depth 3+ is a flag.
3. **Recent commits** — commits touching the role's files in roughly the last 24 hours (basis for "wrapped").

If a role has no handoff and empty inbox, report as "no recent activity on file."

## Per-role block format

```
### {role}
- Wrapped: {what the role completed since the last standup, or "nothing on file"}
- Queued: {open threads / first-steps from the latest handoff, or inbox items not yet picked up}
- Blocked: {any blocker — inbox depth 3+, unanswered message 2h+ — or "none"}
```

Keep each line to one sentence. The digest is a scan, not a report.

## Digest file format

Write to `war-room/standup-{YYYY-MM-DD}.md`:

```
# Standup — {YYYY-MM-DD}

_Generated by the standup skill at {HH:MM local}._

## Team flags
{One-line list of anything needing attention today. Or "none".}

## Per role
{one block per role, format above}
```

Commit: `docs: war-room: standup {YYYY-MM-DD}`.

## What this skill does not do

- Does not message any role.
- Does not resolve blockers — surfaces them for PM to act on.
- Does not replace the dashboard. Standup is a once-daily narrative snapshot.
