# Role Templates

Starting-point templates for common role types used in the bootstrate framework.

HR Manager reads these during Phase 1 of onboarding (recruiter research phase) to
understand the shape of a role before customizing for the specific instance.

## How to use

1. Identify which template matches the role you are onboarding.
2. Copy the template and replace all `{PLACEHOLDER}` values with instance-specific values.
3. Review the resulting role prompt with the CEO before activating the role.

## Templates

| File | Role type | Pattern |
|------|-----------|--------|
| `coordinator.tmpl.md` | Coordinator / triage hub | Active continuous loop, inbox routing |
| `portfolio-manager.tmpl.md` | Portfolio Manager | Cowork self-scheduled, morning report |
| `pa-cowork.tmpl.md` | Personal Assistant | Cowork scheduled, inbox/calendar |
| `engineer.tmpl.md` | Code Engineer | Work-driven loop, sprint-based |
| `validator.tmpl.md` | Validator | Work-driven loop, validation cycle |
| `designer.tmpl.md` | Designer | On-demand, deliverable-based |

## Version note

These templates are based on V1.2 role prompts. Templates will be updated
post-Phase-2 when HR Manager role prompt rewrites are complete.
